# promptics

**Agents write the software. People are the bottleneck now. We build the methods and tools for what comes next.**

Agents write the code today, and tomorrow they automate the rest of the workflow. From that moment the human is the bottleneck: outputs to verify, plans to judge, questions to answer, input to supply, more than anyone can keep up with. promptics builds the methods and tools that make this work fit a person's day: requests that arrive bundled and in context, review by intent instead of by diff, and time that goes back into work that creates value for people.

## How we work

We build our tools with our own tools. Agents build our software in small slices on our own infrastructure. A person approves every plan and every merge, and every run is traced and reviewed. Working this way shows us where people, teams and methods start to struggle, and that is what we build for next. It is early and in private preview.
